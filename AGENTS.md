# Repository agent instructions

This project was built with the microsoft-foundry skill. Before working on or answering questions about foundry agents, read the microsoft-foundry skill first.

Keep retrieval restricted to the Microsoft 365 Copilot Retrieval API `sharePoint` data source. Never add OneDrive, email, Teams messages, or Copilot connector content unless the user explicitly changes the product requirements. Preserve delegated user authorization, site-scope validation, fail-closed post-filtering, source citations, and tests.

If you are in VS Code, read the vscode-microsoft-foundry skill first.
